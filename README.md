# 📺 YouTube Channel Stats

Projeto simples feito com **HTML, CSS e JavaScript** consumindo a API do YouTube para mostrar:

- 👥 Inscritos
- 👀 Views totais
- 🎥 Quantidade de vídeos

---

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
- YouTube Data API v3

## ⚙️ Como usar

1. Clone o repositório
2. Adicione sua API Key do YouTube
3. Coloque o ID do canal
4. Abra o `index.html`

---

## 📚 Aprendizados

Esse projeto foi feito para praticar:

- Consumo de APIs
- `fetch()`
- Manipulação do DOM
- Promises
- JSON

---

## 🔑 Importante

A API Key utilizada foi restringida no Google Cloud para maior segurança.
